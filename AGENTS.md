# AGENTS.md — bsgusa / bala-voice (public engagement)

Conventions for AI agents (and humans) working in this repo.

## Start here

1. Read [`ROADMAP.md`](./ROADMAP.md) — milestones; work the `[NOW]` item.
2. Read [`backlog/priorities.md`](./backlog/priorities.md) — the detailed task list.
3. Skim the latest file in [`reports/`](./reports/) for recent context.

## Purpose

`bala-voice` is the front door — issues, discussions, open roadmap mirror, and a published response-time promise for the Balamonis new world.

## Layout

| Path | What lives there |
|---|---|
| `.github/ISSUE_TEMPLATE/` | Collab proposal, gap report, connection request |
| `.github/CONTRIBUTING.md` | How to engage, branch, PR |
| `docs/RESPONSE_PROMISE.md` | The 7/14/7 response-time promise |
| `reports/` | Dated build logs |
| `ROADMAP.md` / `backlog/priorities.md` | Milestones + task list |

## Working rules

- **Work on a branch, never `main`.** Small commits with clear messages.
- **Truthful claims only.** No fabricated response times, customer counts, or engagement metrics.
- **Response-time promise:** issues acked ≤7 days, PRs reviewed ≤14 days, email ≤7 days. Reviewed each session.
- **Before ending a session:** update `ROADMAP.md`, `backlog/priorities.md`, append to `reports/LOG.md`.

## Stack

Markdown + YAML + GitHub issue templates. No build step.
