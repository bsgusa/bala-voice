## Vision

**bala-voice is the front door.**

This is where the world meets Shiv Balamonis's work. Every repo in the new world points here for public engagement: file an issue, start a discussion, watch the public roadmap, or propose a collaboration.

We build in public. We respond in public. We say who we are and what we're building — honestly, without fabrication.

---

## How to engage

| Channel | Purpose | Where |
|---|---|---|
| **Issues** | Propose a collab, report a gap, request a connection | `bala-voice` / `Issues` |
| **Discussions** | Open conversation about direction, ideas, questions | `bala-voice` / `Discussions` |
| **Pull requests** | Contribute code, docs, or connections | Via `bala-weave` templates |
| **Roadmap** | See what's `[NOW]`, `[NEXT]`, `[LATER]` | Each repo's `ROADMAP.md` |
| **Reports** | Read dated build logs and trend briefs | Each repo's `reports/` |

---

## Public roadmap (mirror)

Every repo in the new world maintains its own `ROADMAP.md` with `[NOW]`, `[NEXT]`, and `[LATER]` sections. `bala-nexus` aggregates them into one world map. You can always see what is being built, what is next, and what is parked.

---

## Response-time promise

- **Issues:** acknowledged within 7 days, triaged within 14.
- **Pull requests:** reviewed within 14 days.
- **Direct email (`support@balamonis.com`):** responded within 7 days.

This is a promise we can keep, not a marketing claim. It will be reviewed and adjusted as the team grows.

## Connection map

```
bala-voice  (public engagement)
    │
    ├─ Issues → triage → backlog (any repo)
    ├─ Discussions → ideas → bala-pulse signals
    ├─ PRs → bala-weave templates → merged to main
    └─ Roadmap → public view of NOW/NEXT/LATER
```

---

## Working rules

- **Work on a branch, never `main`.** Small commits with clear messages.
- **Truthful claims only.** No fabricated response times, customer counts, or engagement metrics.
- **Before ending a session:** update `ROADMAP.md`, `backlog/priorities.md`, append to `reports/LOG.md`.

---

## Getting started

1. Read `AGENTS.md`.
2. Open an issue to introduce yourself and say how you want to connect.
3. Browse `bala-nexus` for the world map of repos.
4. Contribute via `bala-weave` PR templates.
