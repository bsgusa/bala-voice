# Response-Time Promise — bsgusa / bala-voice

Reviewed each session. This is a promise we can keep, not a marketing claim.

## The promise

| Channel | Commitment | Review cadence |
|---|---|---|
| Issues | Acknowledged within 7 days | Each session |
| Pull requests | Reviewed within 14 days | Each session |
| Email (`support@balamonis.com`) | Responded within 7 days | Each session |

## Why these numbers

- Single founder, small surface. 7/14/7 is realistic today.
- If volume grows, the promise is revisited — not silently broken.
- Every miss is logged in `reports/LOG.md` with a reason.

## Truthful-claims rule

No fabricated response times, customer counts, or engagement metrics. If we can't evidence it, we don't claim it.

## How to hold us to it

Open an issue in `bala-voice` if a response exceeds the promise. It will be triaged as `[NOW]`.
